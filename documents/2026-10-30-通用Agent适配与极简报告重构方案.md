## 0. 三块各一句话结论

1. **通用 Agent 适配**：以统一 `HostProtocol`（三件套契约：非交互调用形态 / 输出解析器 / `--version` 探活）取代「一家一适配」，本期深度修复 codex、claude_code 两个原生适配器，opencode/agent/script 统一到该协议补齐，新增 cursor-agent 作为第六宿主（本机唯一可真机冒烟、作为协议首个落地验证）；api/standalone 维持纯 API 宿主不动，Gemini CLI / pi 本期不实现、仅在协议文档留空位。
2. **流程强化**：四步流水线与实验级断点续传已存在，硬卡点在于 `simple`/`pipeline` 依赖 `input()` 停盘、`plan --generate` 强制 summary_model、`evaluate` 缺 `--voting-models` 即交互死锁、模型发现只认 opencode——全部通过「一次性 profile + 非交互模式 + 宿主导出模型发现」消除，达到一键闭环。
3. **极简报告**：报告已是自包含单文件（CSS/JS 内联、无外链、主交付物 base64 内联），改造成「结论先行的三层结构（payload 组装 / 模板 / 渲染入口）」，首屏一页式 = 一句话结论大字 + 三个关键指标 + 有/无对比卡片 + 红绿用例清单，明细全折叠 `<details>`，术语全大白话；补齐红绿清单层并把术语替换覆盖到技术区。

**通用层「任何 agent 用」的真正缺口（工部结论）：**

1. **缺统一宿主协议规范**：`base.py` 有 capabilities 声明，但没有强制「三件套」契约——① 非交互调用形态（stdin / --print / exec / run）；② 输出解析器（text / usage / exit_code）；③ 探活方式（`--version` 先于真实调用）。新接宿主无最小可照抄模板。
2. **skill_injection 只有约定没有实现**：`agents-md`（codex）与 `claude-skills-dir`（claude）只是字符串声明，注入/清理逻辑在 `subject_adapter/` 而不在 executor 内，两处语义未对齐。
3. **错误语义不统一**：CLI 不存在时 `validate_config` 返回 `(False, msg)` 是对的，但执行中途 CLI 崩溃（非零 exit_code）与超时的区分、stderr 截断长度（200 字符）各家不一。

**入口与模型发现断点（本人核实）：**

- 入口仍是问答式：`cli.py: cmd_simple/_ask` 问 4 题；`workflow.py: default_stage_confirm` 默认 4 阶段停盘等回车；非交互 Agent 在 `input()` 处卡死或 EOF 跳过。
- 模型发现 opencode 中心化：`cli.py` 多处 `get_opencode_models()`；`ClaudeCodeExecutor/CodexExecutor.list_models` 返回 `config["available_models"]`（默认空）。
- MCP Server（`mcp_server.py`）只暴露 `evaluate_skill/analyze_skill/check_connectivity`，无 `host/profile` 参数、无分步工具。
- 配置未成 profile：`eval-config.json` 仅文档提及，主链无 profile 加载器，无 `--config/--profile` 入口。

### 1.2 目标态

- **统一 HostProtocol**：凡「可非交互调用 + 能输出结构化结果 + 有 `--version` 探活」的 CLI 型 agent 都走同一协议，不再一家一适配。
- **本期宿主清单（拍板见第五章）**：深度修复 `codex`、`claude_code`；统一补齐 `opencode`、`agent`、`script`；新增 `cursor-agent`；`api/standalone` 不动；Gemini CLI / pi 只留协议空位。
- **配置「一次性 + 可复用 profile」**：一份 JSON 承载全部评测参数，所有入口复用；非交互模式下缺参返回结构化 `needs_user_input` 而非 `input()` 阻塞。

### 1.4 验收标准

- 无 TTY 环境下 `python3 -m evaluator.cli simple --profile eval-config.json --non-interactive` 全程无 `input()` 阻塞，跑通 plan→run→evaluate→report。

- `hosts` 子命令输出所有宿主 capabilities + 注入约定 + CLI 是否已安装。
- cursor-agent 在真机冒烟通过（本机唯一可真机验证的宿主），作为 HostProtocol 首个落地证明。

### 2.1 现状断点 + 「一键自动化被卡住」卡点清单（逐条核实，未编造）

### 2.2 目标态

- **一键闭环**：`plan` 完成自动 `run → evaluate → report`，或一条 `pipeline --auto --profile X` 跑到底。
- **验资（preflight）与 `needs_user_input` 边界**：
  - 必须问（不可推断/生成）：任务需求（除非用户明确授权自动生成）、blocking 敏感资源（账号/密码/API key/数据库连接/浏览器环境）、真实输入文件（用户未授权生成时）。
  - 可自动推断：`summary_model`（默认第一个评委）、`voting_models`（默认第一个被测模型）、`models`（默认发现的前 1-2 个）、非 blocking 资源（defaulted 并在报告标注）。
- **失败重试 + 断点续跑**：基础设施错误自动重试并标 `invalid`；断言失败标 `failure`；阶段级 `--resume` 与明确状态机。

### 2.4 验收标准

- `python3 -m evaluator.cli pipeline --profile eval-config.json --auto` 无 TTY 一条命令产出 `report.html`，退出码 0。

- **风险**：summary_model 默认取第一个评委可能与用户预期不符，报告 meta 需显式标注「总结模型 = X（默认）」。

## 3. 极简报告（结论先行 + 三层结构 + 自包含）

### 3.1 现状断点（工部 + 本人核实）

**自包含性现状：报告已基本自包含。** CSS 内联 `reporting.py: _report_css()`、JS 内联 `_report_js()`、无 `<link>`/外部字体/CDN/外部图片；主交付物下载 `_artifact_href(..., use_data_uri=True)` 走 base64；表格/幻灯片预览用 `<pre>`/`<table>`/纯 HTML。

**残留非自包含点（2 处）：**
1. 非主交付物（过程证据）下载链接是相对路径（`use_data_uri=False`），报告单独拷走即失效。
2. 主交付物 base64 无条件内联，无大小预算，大文件（xlsx/pdf）会让单文件体积失控。

**结构耦合（工部结论）：** `reporting.py` 1858 行、62 个函数，数据组装（`build_report_payload`）与渲染（`_render_*` 15 个 / `_artifact_*` 10 个）耦合在同一文件，无分层。

**黑话残留（技术区绕过术语映射）：**

### 3.2 目标态（拍板标准，见第五章）

- **一页式首屏**：一句话结论（verdict 大字）+ 三个关键指标 + 有/无对比卡片 + 红绿用例清单；明细全部折叠 `<details>`；手机竖屏首屏不滚到第二屏。
- **三层结构**：payload 组装（纯数据）/ 模板（单独 .html 模板或模板函数文件）/ 渲染入口，替换现有 1858 行单文件耦合。
- **大白话 100% 覆盖**用户可见文案，符号黑话只允许在折叠的「原始数据」层。
- **自包含单文件不变**：内联 CSS/JS、图片 data:URI 或纯 SVG；超预算附件降级为摘要。

## 5. 决策结论（已拍板，不留开放问句）

1. **宿主范围清单（本期）**
   - **原生适配深度修复**：`codex`、`claude_code`（按第 1.3-B 清单落地）。
   - **已有但统一协议补齐**：`opencode`、`agent`、`script`。
   - **新增第六宿主**：`cursor-agent`（本机唯一可真机冒烟，作为 HostProtocol 首个落地验证）。
   - **维持不动**：`api`、`standalone`（纯 API 宿主，无文件能力，产物型任务继续显式拦截）。
   - **本期不实现**：Gemini CLI、pi——仅在 `references/host-protocol.md` 留接入空位。
   - **统一原则**：凡「可非交互调用 + 能输出结构化结果 + 有 `--version` 探活」的 CLI 型 agent 都走同一 HostProtocol，不再一家一适配。

2. **报告「简单」标准**
   - 一页式首屏 = **一句话结论（verdict 大字）+ 三个关键指标 + 有/无对比卡片 + 红绿用例清单**；明细全部折叠进 `<details>`。
   - 手机竖屏首屏不滚到第二屏。
   - 术语全部大白话（对照 `terminology.py` 替换表）。
   - 自包含单文件不变（内联 CSS/JS、图片 data:URI 或纯 SVG）。

3. **立 HostProtocol 规范文档**：要立，放 `references/host-protocol.md`，内容 = 三件套契约（非交互调用形态 / 输出解析器 / 探活方式）+ capabilities 声明 + skill_injection 注入/清理 + 错误语义统一（崩溃/超时/stderr 截断）。目录骨架见第 1.3-A。
